# Bundled web fonts

These files are self-hosted so the site makes **no external requests** — no CDN,
no `fonts.googleapis.com`, nothing to block or leak a referrer. Each is the
latin subset only.

All three families are licensed under the **SIL Open Font License 1.1**, which
permits redistribution. They are *not* covered by the Apache-2.0 licence that
covers the rest of this repository.
